# Personal Profile - Pulithevan Dhananchezhian

This project is a simple **personal profile webpage** built using semantic HTML.  
It introduces Pulithevan Dhananchezhian, a Java Full Stack Developer, and highlights his background, skills, and contact information.

---

## 📖 Project Overview
The webpage contains:
- **Header Section**: Name and professional title.
- **About Me Section**: A short introduction and personal interests.
- **Skills Section**: A list of technical skills.
- **Contact Section**: Email, phone number, and LinkedIn profile.

---

## 🛠️ Technologies Used
- **HTML5** for structure
- **Semantic tags** (`<section>`, `<h1>`, `<h2>`, `<p>`, `<ul>`, `<li>`)
- **Responsive meta tags** for mobile-friendly design

---

## 🚀 How to Run
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. The profile page will render with all sections displayed.
